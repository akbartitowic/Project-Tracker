1 Ringkasan Sistem

Project Tracker adalah aplikasi manajemen internal untuk software house / tim IT yang mengcover siklus penuh dari:

Prospek → Sales Pitch → Presales → Project Execution → Finance Monitoring → Laporan
🔑 Admin / Project Manager
Akses penuh ke semua modul termasuk keuangan, pengaturan sistem, dan laporan.
Semua permissions
💻 Board Member
Developer, QA, Designer — akses ke project board dan log manhour.
project_board.* · profile.*
🔧 Freelance
Kontraktor eksternal — hanya bisa melihat board dan update status task.
project_board.read · project_board.update · profile.*

Pola komunikasi penting

  • Frontend React memanggil semua data via /api/* menggunakan Axios.
  • Autentikasi menggunakan Laravel Sanctum (Bearer token, expiry configurable, default 720 menit).
  • Semua route API dilindungi auth:sanctum + permission:{slug} middleware.
  • PDF quotation di-generate server-side via dompdf dan disimpan di storage.
  • Email dikirim asinkron via Laravel Queue (database driver).

6.3 Project Lifecycle

flowchart TD A([Project dibuat\nstatus: Planning]) --> B[Setup Project\nAdd Members, Role Quotas\nHourly Rate] B --> C[Buat Tasks\nParent + Subtask\nAssignee, estimated_hours\ndue_date, start_date] C --> D{Mulai kerja\nstatus: In Progress} D --> E[Log Manhours\nPer tanggal per role] D --> F[Update Task Status\nTo Do → In Progress → Done] E --> G[Monitor Board\nKanban, Gantt, Dashboard] F --> G G --> H{Semua task Done?} H -->|Ya| I([Project Done]) H -->|Tidak| D I --> J[Generate Report\nEfficiency, Financial\nRealization] style A fill:#312e81,color:#a5b4fc style I fill:#166534,color:#86efac style J fill:#1e3a8a,color:#93c5fd

Aturan Subtask

  • Nesting maksimal 1 level — subtask tidak bisa punya subtask.
  • estimated_hours parent = sum estimated_hours subtask yang is_billable = true.
  • Quota Scrum dihitung dari: subtask ATAU parent yang tidak punya subtask.
  • Rush hour (rush_hour = true) menggunakan multiplier 1.3×.
